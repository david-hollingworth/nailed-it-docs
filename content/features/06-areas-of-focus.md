Life Areas (e.g. Health, Career, Relationships, Finance) are the categories that
Goals, Tasks, and Habits are tagged with. This feature covers the dedicated view for
browsing and filtering by them.

## FEAT-0601 Areas of Focus view

| | |
|---|---|
| **Status** | Draft |
| **Phase** | 1 |

### Description

A dedicated view lists all Life Areas, each showing its associated Goals, Tasks, and
[Habits](/nailed-it-docs/features/09-habit-tracking).

## FEAT-0602 Cross-app Life Area filtering

| | |
|---|---|
| **Status** | Draft |
| **Phase** | 1 |

### Description

The whole app — vision board, goal list, task list — can be filtered by one or more
Life Areas.

## FEAT-0603 Attention indicator per Life Area

| | |
|---|---|
| **Status** | Draft |
| **Phase** | 1 |

### Description

A simple visual indicator shows relative attention across life areas (e.g. count of
active goals/tasks per area), to surface imbalance.

#### Note

This is intentionally lightweight — not a scored "life wheel" — unless that's wanted
in a later phase.
